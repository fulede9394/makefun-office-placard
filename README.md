## The placard

> This printer has been 'warming up' since 2019. Please do not feed it your hopes.

## How it works

`main.ts` writes the placard — a single line, 80 characters — to `/output/entry.txt`, after checking it against the competition gate (1–180 characters, non-blank, one line).

Run it with:

```sh
node main.ts
```
